# Spice.ai .NET SDK v0.5.1 Release Notes

## Fixes

### HTTP Calls with a Spice Cloud Key

With a Spice Cloud key (`appId|key`) and a Spice Cloud address, the HTTP client sent `Authorization: Basic`, which the Spice Cloud data plane rejects. `IsSpiceReadyAsync` returned `false`, and `SearchAsync`, `RefreshDatasetAsync` and `GetRuntimeStatusAsync` failed with `401 Unauthorized`. Flight calls (`SqlAsync`, `SqlWithParamsAsync`) were not affected.

HTTP calls now send the full key as `X-API-Key` for every key and address, like the other Spice SDKs. The Flight Basic auth handshake for Spice Cloud keys does not change. ([#39](https://github.com/spiceai/spice-dotnet/pull/39))

### TLS Certificates for Parameterized Queries

`SqlWithParamsAsync` now uses the TLS root certificate and client certificate files set with `WithTlsRootCertificate` and `WithTlsClientCertificate`. Before, parameterized queries to a runtime with a private CA or mTLS failed the TLS handshake. ([#33](https://github.com/spiceai/spice-dotnet/pull/33))

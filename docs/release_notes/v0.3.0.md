# Spice.ai .NET SDK v0.3.0 Release Notes

## New Features

### Parameterized Queries with ADBC Protocol

This release adds support for parameterized queries using the ADBC (Arrow Database Connectivity) protocol with positional placeholders. This provides better type safety and support for the prepare/bind/execute pattern.

#### New Methods

- `SpiceClient.QueryWithParams(string query, params object?[] parameters)` - Execute a parameterized SQL query and return results as an Arrow stream

#### Usage

```csharp
using Spice;
using Spice.Params;

using var client = new SpiceClientBuilder().Build();

// Basic usage with type inference
var data = await client.QueryWithParams(
    "SELECT * FROM products WHERE id = $1 AND price >= $2",
    42,      // Inferred as Int32
    10.50    // Inferred as Double
);

// Explicit type control with Param class
var data = await client.QueryWithParams(
    "SELECT * FROM orders WHERE customer_id = $1 AND order_date >= $2",
    Param.Int64(12345),
    Param.Date32(new DateTime(2024, 1, 1))
);
```

### The `Param` Class

A new `Param` class provides explicit control over Arrow data types:

| Method                                      | Arrow Type              | .NET Type      |
| ------------------------------------------- | ----------------------- | -------------- |
| `Param.Int8(value)`                         | Int8                    | sbyte          |
| `Param.Int16(value)`                        | Int16                   | short          |
| `Param.Int32(value)`                        | Int32                   | int            |
| `Param.Int64(value)`                        | Int64                   | long           |
| `Param.UInt8(value)`                        | UInt8                   | byte           |
| `Param.UInt16(value)`                       | UInt16                  | ushort         |
| `Param.UInt32(value)`                       | UInt32                  | uint           |
| `Param.UInt64(value)`                       | UInt64                  | ulong          |
| `Param.Float(value)`                        | Float                   | float          |
| `Param.Double(value)`                       | Double                  | double         |
| `Param.String(value)`                       | String                  | string         |
| `Param.Binary(value)`                       | Binary                  | byte[]         |
| `Param.Boolean(value)`                      | Boolean                 | bool           |
| `Param.Date32(value)`                       | Date32                  | DateTime       |
| `Param.Date64(value)`                       | Date64                  | DateTimeOffset |
| `Param.Time32(value, unit)`                 | Time32                  | TimeSpan       |
| `Param.Time64(value, unit)`                 | Time64                  | TimeSpan       |
| `Param.Timestamp(value, unit, tz?)`         | Timestamp               | DateTimeOffset |
| `Param.DurationSeconds(value)`              | Duration (seconds)      | TimeSpan       |
| `Param.DurationMilliseconds(value)`         | Duration (milliseconds) | TimeSpan       |
| `Param.DurationMicroseconds(value)`         | Duration (microseconds) | TimeSpan       |
| `Param.DurationNanoseconds(value)`          | Duration (nanoseconds)  | TimeSpan       |
| `Param.Decimal128(value, precision, scale)` | Decimal128              | decimal        |
| `Param.Decimal256(value, precision, scale)` | Decimal256              | decimal        |
| `Param.Null()`                              | Null                    | null           |

### Type Inference

When you don't use the `Param` class, types are inferred automatically:

| .NET Type        | Inferred Arrow Type                 |
| ---------------- | ----------------------------------- |
| `sbyte`          | Int8                                |
| `short`          | Int16                               |
| `int`            | Int32                               |
| `long`           | Int64                               |
| `byte`           | UInt8                               |
| `ushort`         | UInt16                              |
| `uint`           | UInt32                              |
| `ulong`          | UInt64                              |
| `float`          | Float                               |
| `double`         | Double                              |
| `string`         | String                              |
| `byte[]`         | Binary                              |
| `bool`           | Boolean                             |
| `DateTime`       | Timestamp (microseconds, UTC)       |
| `DateTimeOffset` | Timestamp (microseconds, UTC)       |
| `TimeSpan`       | Duration (nanoseconds)              |
| `decimal`        | Decimal128 (precision=38, scale=18) |
| `null`           | Null                                |
